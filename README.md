# 开饭参谋 · 报人数、报预算，摆好一桌麦当劳

> 聚餐点麦当劳最烦的不是吃什么，是**人多嘴杂**：有人减脂、有人不吃牛肉、有人不吃辣，还得卡住预算。
> 把这些交给 AI —— 它读麦当劳**实时菜单**、按人算忌口、给三套方案，并且**每一单都交给麦当劳官方算价引擎核过价**才敢报给你。

一个真实调用 **麦当劳 MCP（mcp.mcd.cn）** 的团餐搭配助手。不是演示，不是 mock：菜单、价格、热量、优惠券、活动、下单，全部走官方接口。

---

## 它到底做了什么

输入三件事：**几个人吃、一共多少预算、谁有什么忌口**。

输出三套方案，可切换对比：

| 方案 | 策略 |
| --- | --- |
| 吃得均衡 | 主食 + 共享小食 + 饮品 + 甜品，人均最舒服 |
| 最省钱 | 优先双人餐 / 套餐，把人均压到最低 |
| 轻卡减脂 | 挑低热量主食 + 0 卡饮品，热量算给你看 |

每一套都会：

1. **从官方菜单里挑**（`query-meals`，本次实测 127 个在售餐品，剔除了周边、玩具、酱包）
2. **按人算忌口** —— 「不吃牛肉 / 不吃辣 / 不吃炸物」是**全桌硬约束**，「减脂 / 素食 / 不要酱 / 去冰」是**个人诉求**，只影响那一份
3. **交给麦当劳算价**（`calculate-price`）拿到真实应付价、原价和优惠
4. **核不过就换** —— 如果某一单项的官方小计和菜单价对不上（比如需要选子项的多人分享餐，官方会按默认高价计），直接把这件商品**拉黑重搭**，最多 3 轮，直到整单价格对得上才报给你
5. **算热量** —— 拿官方营养表（`list-nutrition-foods`，158 条）匹配；组合套餐查不到时，拉 `query-meal-detail` 把子项拆开逐项累加
6. **告诉你今天店里有什么** —— 活动日历、卡包里的券、一键领券

最后还能**真的下单**（`create-order`），二次确认后创建真实到店订单。

## 快速开始

### 1. 申请麦当劳 MCP Token

去 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录，在控制台激活领取 MCP Token。免费。

### 2. 配置

```bash
cp .env.example .env
```

编辑 `.env`，只填一个必填项：

```ini
MCD_TOKEN=你的麦当劳MCP Token
DEFAULT_CITY=广州          # 默认城市
DEFAULT_STORE=1400359      # 默认门店号（可选，留空则自动取搜索结果第一家）
```

### 3. 跑起来

```bash
node server.js
# 打开 http://localhost:5173
```

零依赖，Node 18+ 即可（用到内置 `fetch`）。不需要 `npm install`。

### 4. 用

1. 确认 / 切换门店（支持按城市或关键词搜）
2. 选人数（1–8 人）
3. 选预算（或手填）
4. 给每个人点上忌口
5. 点「摆一桌」→ 三套方案切换着看 → 复制清单，或直接让 MCP 下单

## 使用示例

**场景：3 个人，¥90，第 1 位在减脂，第 3 位不吃牛肉**

```
【开饭参谋】3 人 · 预算 ¥90 · 麦当劳广州天源路餐厅
方案：吃得均衡

SHARE 共享大份
  1× 麦麦周末双人餐          ¥49.9
     ↳ 2 人份组合，原价 ¥85.5，人均 ¥24.9，比两份单点更省

  1× 酥脆无双套餐            ¥20.0   243kcal

  1× 蘸酱脆皮鸡块            ¥11.9
```

小票底部会盖一行：`价格由麦当劳 MCP calculate-price 实时核出 · 官方价`。

## 目标用户

- **聚餐发起人** —— 同事下午茶、社团活动、家庭出行，需要一单搞定所有人的忌口
- **减脂 / 控卡人群** —— 想吃麦当劳又要盯热量，让它挑低卡组合
- **预算敏感型** —— 有明确的钱数上限，想知道这个钱能吃到什么
- **麦当劳 MCP 开发者** —— 想看一个把 `calculate-price` 真正用于风控的完整样例

## 项目结构

```
mcd-kaifan/
├── server.js              # HTTP 服务 + 路由 + 算价校验循环 + AI 点评
├── mcp.js                 # 麦当劳 MCP 客户端（Streamable HTTP + JSON-RPC，零依赖）
├── lib/
│   ├── mcd.js             # MCP 业务封装：门店/菜单/营养/算价/券/活动/下单
│   └── planner.js         # 搭配引擎：人数 × 预算 × 忌口 → 三套方案
├── public/index.html      # 移动端 H5（单文件，无构建）
├── tools/                 # MCP 探测脚本，用于摸清接口返回结构
├── .env.example
└── mcp-config.example.json
```

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | MCP 连通性自检，返回可用工具数 |
| GET | `/api/stores?city=广州&keyword=天源路` | 搜索可点餐门店 |
| GET | `/api/store` | 默认门店 + 菜单分类统计 |
| POST | `/api/plan` | 生成方案（body: `headcount`, `budget`, `prefs`, `storeCode`） |
| GET | `/api/plan/:id` | 轮询方案（AI 点评异步回来） |
| GET | `/api/coupons` | 卡包里的麦麦省优惠券 |
| POST | `/api/coupons/claim` | 一键领取所有可领券 |
| GET | `/api/campaigns` | 今日营销活动日历 |
| POST | `/api/order` | 创建真实订单（需 `confirm: true`） |

## 环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `MCD_TOKEN` | ✅ | 麦当劳 MCP Token |
| `DEFAULT_CITY` | | 默认城市，默认「广州」 |
| `DEFAULT_STORE` | | 默认门店号 |
| `PORT` | | 端口，默认 5173 |
| `ENABLE_ORDER` | | 设为 `0` 关闭真实下单（公网部署建议关闭） |
| `TOKLENS_KEY` | | 可选，配置后启用 AI 一句话点评 |

## 说明

- 参赛作品，由参赛者独立开发，**非麦当劳官方产品**。
- 餐品、价格、供应状态以麦当劳官方渠道实时结果为准。
- 下单功能会创建**真实订单**，公网部署时请把 `ENABLE_ORDER=0`。
- AI 点评的餐品建议仅供参考，不构成医疗或营养专业建议。
