这一步在本地版会发生什么×

在线版是纯静态页面，浏览器不能直接连麦当劳 MCP（MCP 不开 CORS），所以这里只做演示。 用源码跑本地版，点同一个按钮就会真的走下面这条链：
POST https://mcp.mcd.cn Authorization: Bearer •••• 1. query-meal-detail → 拿默认子项（套餐拆解） 2. calculate-price → 官方核价，覆盖本地估算 3. create-order → 生成真实订单（到店取餐） ↩ { code:200, data:{ orderId:"...", payAmount:"...", pickupCode:"..." } }
本地跑法：
cd mcd-kaifan → 填好 .env 里的 MCD_TOKEN → node server.js → 打开 localhost:5173
注意：create-order 会产生真实订单并占用门店库存，所以按钮后面还有一层确认弹窗。
